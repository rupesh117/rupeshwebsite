# Security Policy

## Supported Versions

The following versions are currently supported with security updates.

| Version | Supported |
| ------- | ---------- |
| 1.x.x   | ✅ |
| < 1.0   | ❌ |

---

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly.

### Contact

Please report vulnerabilities through:

- GitHub Issues (for non-sensitive issues)
- Private email: security@rupesh.tech

---

## What to Include

When reporting a vulnerability, please include:

- Vulnerability description
- Steps to reproduce
- Proof of Concept (PoC)
- Screenshots or logs (if available)
- Potential impact

---

## Response Time

You can expect:

| Action | Time |
| ------ | ---- |
| Initial Response | Within 48 hours |
| Status Update | Within 5 business days |
| Fix or Mitigation | Based on severity |

---

## Responsible Disclosure

Please do not publicly disclose vulnerabilities until they have been investigated and resolved.

We appreciate responsible disclosure that helps improve the security of this project and protect users.

---

## Security Recommendations

Users are encouraged to:

- Keep systems and dependencies updated
- Use strong passwords and authentication
- Avoid exposing credentials or API keys
- Monitor logs for suspicious activity
- Follow cybersecurity best practices

---

Thank you for helping improve the security and reliability of this project.
